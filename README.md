# Nexus — Privacy-first local AI assistant

Nexus is a local AI assistant that runs entirely on your machine. It sees via the camera, listens via the microphone, speaks via the speakers, and thinks via a local LLM.

## Installation

### From source

```bash
git clone https://github.com/pikkst/nexus-ai-assistant.git
cd nexus-ai-assistant
pip install .
```

### Development install

```bash
pip install -e ".[dev]"
```

## Usage

After installation, launch the assistant with:

```bash
nexus
```

For the graphical workspace UI, use:

```bash
nexus --ui
```

## Requirements

- Python 3.11+
- Windows 11 (primary), Linux, macOS (secondary)
